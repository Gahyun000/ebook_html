## SCR-006 LLM 설정 — 상세(대표 화면)

### 구성요소
| 요소 ID | 유형 | 표시값 | 동작 | 입력 검증 | 권한/조건 |
|---|---|---|---|---|---|
| U-PROVIDER | select | providers(self/anthropic 등) | provider 선택 | 허용값 | — |
| U-BASEURL | text | base_url | 엔드포인트 입력 | URL 형식 | — |
| U-USERID | text | user_id | 사용자 식별 | 비어있으면 미구성 | — |
| U-APIKEY | password | 마스킹(api_key_masked) | 키 입력(서버 저장) | 저장 후 마스킹 표기 | 서버 전용·비커밋 |
| U-MODEL | text | model | 모델명 | 필수 | — |
| U-TIMEOUT | number | timeout(기본 45) | 타임아웃(초) | 양수 | — |
| U-ENABLED | toggle | enabled | 사용 on/off | — | — |
| U-TEST | button | "연결 테스트" | /test 호출 | 중복 클릭 방지 | — |
| U-SAVE | button | "저장" | PUT 저장 | 저장 중 재제출 방지 | — |

### 화면 상태
| 상태 | 조건 | 표시 | 허용 동작 |
|---|---|---|---|
| 초기 | 미설정 | 기본값·마스킹 빈값 | 입력 |
| 로딩 | 저장/테스트 중 | 스피너·버튼 비활성 | 취소 대기 |
| 성공 | 저장/연결 OK | 마스킹 키·연결됨 표시 | 재편집 |
| 오류 | 연결 실패/검증 실패 | 사유 메시지(내부경로·키 비노출) | 재입력 |

### 메시지
| 코드 | 상황 | 사용자 메시지 | 후속 |
|---|---|---|---|
| M-LLM-OK | 연결 성공 | 연결됨(모델 X) | 저장 유지 |
| M-LLM-FAIL | 연결 실패 | 엔드포인트/키 확인 필요 | 재입력 |
| M-LLM-FALLBACK | 미설정 | 설정 없이 폴백 응답 | 설정 유도 |

- [ ] 긴 텍스트/작은 화면 깨짐 점검(각 화면 실측 필요)

- [ ] 색상 외 상태 구분(아이콘/문구) 점검

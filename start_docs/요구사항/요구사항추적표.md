## 점검 규칙
- 승인 요구사항에 설계 또는 테스트가 비어 있으면 출고할 수 없다.
- 요구사항 없는 코드/화면은 제거하거나 변경승인을 받는다.
- 폐기 요구사항도 사유·대체 요구사항을 남긴다.
- T1↑ 요구사항은 하네스 설계·검증기 ID 없으면 G2 불가.
- T2↑ 요구사항은 루프 종료·취소·재개·한도 테스트 없으면 G4 불가.

> 현 상태: 기존 자동 테스트(server/test_*.py, e2e/*.mjs)가 존재하나, 요구사항 기준선 승인 후 TC-ID를 확정하고 실행 증적을 `qc_docs/테스트증적/`에 남겨 '결과'를 갱신한다.

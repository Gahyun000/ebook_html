## 1. 범위
- 대상: 문서→BookPlan 생성(/api/plan), 자기검증, 대화형 부분수정, LLM 게이트웨이

## 3. 상태·한도 (T2+)

- 텔레메트리: `harness/telemetry/`

- 자연어 출력을 쉘/SQL/삭제/배포/외부전송으로 직접 실행 금지
